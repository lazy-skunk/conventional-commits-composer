# Conventional Commits Composer

Conventional Commits 形式のコミットメッセージを組み立てる Web アプリです。

type、scope、description、body、breaking change、footer を入力すると、コミットメッセージのプレビューを作成できます。

## 使う

公開版は次のURLから使えます。

<https://lazy-skunk.github.io/conventional-commits-composer/>

## 使い方

- コミットの type を選びます。
- 必要に応じて scope、body、footer を入力します。
- breaking change がある場合は表現方法を選び、説明を入力します。
- プレビューされたコミットメッセージをコピーして使います。
